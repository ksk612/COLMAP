# 📷 COLMAP & SfM (Structure-from-Motion) 수학적 원리 완벽 정리

사진들로부터 3차원 공간(포인트 클라우드)과 카메라의 위치(포즈)를 복원해내는 **COLMAP(SfM)**의 핵심 흐름과 수학적 원리를 정리한 문서입니다.

---

## 1. 전체 파이프라인 흐름 (Workflow)

COLMAP이 2D 사진들로부터 3D 공간을 만들어내는 과정은 크게 3단계로 나뉩니다.

1. **특징점 추출 (Feature Extraction)**: 각 사진에서 모서리, 질감 등 눈에 띄는 특징점(Keypoint)을 찾고, 고유의 지문(`Descriptor`)을 부여합니다.
2. **특징점 매칭 (Feature Matching)**: 서로 다른 사진들 간에 같은 지점을 가리키는 특징점끼리 짝을 맺어줍니다.
3. **점진적 SfM (Incremental Structure-from-Motion)**: 
   * **에피폴라 기하학(Epipolar Geometry)**을 이용해 잘못된 매칭을 걸러냅니다.
   * **삼각측량(Triangulation)**으로 3D 공간 좌표를 계산합니다.
   * **번들 조정(Bundle Adjustment, BA)**으로 전체 오차를 최소화하며 카메라와 점의 위치를 정밀하게 맞춥니다.

---

## 2. 핵심 수학적 원리 및 수식

### 2.1. 카메라 투영 모델 (Camera Projection Model)
3차원 공간상의 한 점이 2D 사진(픽셀) 위에 어떻게 찍히는지를 나타내는 기본적인 수학적 모델입니다.

$$x = K [R \mid T] X$$

* **기호와 의미:**
  * $X = [X, Y, Z, 1]^T$: 3차원 공간상의 실제 점 좌표 (동차 좌표계)
  * $x = [u, v, 1]^T$: 2D 이미지 상의 픽셀 좌표
  * $K$ (Intrinsic Matrix): 카메라 내부 파라미터 행렬 (초점 거리, 센서 중심 등 카메라 자체의 특성)
  * $R$ (Rotation): 3차원 공간에서 카메라의 회전 각도 ($3 \times 3$ 행렬)
  * $T$ (Translation): 3차원 공간에서 카메라의 위치 이동 값 ($3 \times 1$ 벡터)
  * $[R \mid T]$: 카메라의 외부 파라미터(Extrinsics), 즉 세상 속에서 카메라가 어디에 어떻게 놓여 있는지 나타냅니다.

---

### 2.2. 에피폴라 기하학과 본질 행렬 (Epipolar Geometry & Essential Matrix)
두 장의 사진 사이에 찍힌 점이 **"정말 같은 물리적 공간의 점이 맞는지"** 기하학적으로 검증하는 수식입니다.

$$x'^T E x = 0$$

* **기호와 의미:**
  * $x, x'$: 두 서로 다른 이미지에서 대응되는 2D 픽셀 좌표들
  * $E$ (Essential Matrix, 본질 행렬): 두 카메라 사이의 **상대적인 위치와 회전 관계**를 담고 있는 $3 \times 3$ 행렬
* **원리:** 
  * 만약 두 점이 진짜 같은 곳을 가리킨다면 위 수식의 결과가 0(또는 0에 가까운 값)이 되어야 합니다. 
  * COLMAP은 RANSAC 알고리즘을 사용해 이 조건을 만족하지 못하는 가짜 매칭(Outlier)을 모조리 걸러냅니다.

---

### 2.3. 삼각측량 (Triangulation)
두 개 이상의 사진에서 같은 점의 위치를 찾았고, 카메라의 위치($R, T$)를 알 때, 3차원 공간상의 좌표 $X$를 역으로 계산해내는 과정입니다.

두 카메라의 투영 방정식을 결합하여 선형 방정식을 세웁니다.

$$x = P X, \quad x' = P' X$$

* **기호와 의미:**
  * $P, P'$: 각 카메라의 투영 행렬 ($K[R \mid T]$ 조합)
  * $X$: 우리가 구하고자 하는 **3차원 공간상의 점 좌표 $(X, Y, Z)$**
* **원리:** 
  * 카메라 A에서 점을 향해 쏜 시선과 카메라 B에서 점을 향해 쏜 시선이 **교차하는 3차원 공간상의 한 점($X$)**을 수학적 최소 제곱법(Least Squares)을 통해 찾아냅니다. (이것이 COLMAP의 `points3D.bin`에 저장되는 데이터가 됩니다.)

---

### 2.4. 번들 조정 (Bundle Adjustment, BA)
SfM 과정에서 오차가 누적되면 3차원 점들이 둥둥 떠 있거나 왜곡될 수 있습니다. 이를 바로잡기 위해 **모든 카메라 포즈와 3D 점의 위치를 동시에 미세 조정**하는 최적화 과정입니다.

$$\min_{R, T, X} \sum_{i} \sum_{j} \left\| x_{ij} - \pi(P_j, X_i) \right\|^2$$

* **기호와 의미:**
  * $x_{ij}$: 이미지 $j$에서 실제로 관측된 $i$번째 포인트의 2D 픽셀 위치
  * $\pi(P_j, X_i)$: 3D 포인트 $X_i$를 카메라 $P_j$에 다시 투영(Projection)했을 때 예상되는 이론상의 2D 위치
  * **재투영 오차 (Reprojection Error)**: 실제 찍힌 위치($x_{ij}$)와 계산된 예상 위치($\pi$) 사이의 거리 차이
* **원리:** 
  * 이 오차의 제곱 합을 최소화($\min$)하는 방향으로 카메라의 위치($R, T$)와 3차원 점($X_i$)의 위치를 비선형 최적화 기법(Levenberg-Marquardt 알고리즘 등)을 이용해 동시에 조금씩 수정합니다. 
  * 이 과정을 거쳐야 비로소 NeRF나 3D Gaussian Splatting에 쓰일 만큼 정밀한 3차원 구조가 완성됩니다.
